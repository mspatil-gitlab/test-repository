1. Decision Constructs
    1. if

            process
        
        if condition is True: execution gets inside the if and 'process'
        will be executing.

        if condition is False: nothing will be executing.


    2. if else

        if condition:
            process1
        else:
            process2
        
        if condition is True: execution gets inside the if and 'process1'
        will be executing.

        if condition is False: execution gets inside the else and 'process2'
        will be executing.
